Verify these Databricks workspace features are enabled before starting. Lakebase Change Data Feed (CDF, formerly Lakebase Change Data Feed (CDF)) is in Public Preview and has stricter workspace requirements than most other templates.

- **A workspace on AWS or Azure in a Lakebase Autoscaling region.** Change Data Feed is available in Public Preview on both AWS (`*.cloud.databricks.com`) and Azure (`*.azuredatabricks.net`). A workspace admin must first enable the **Lakebase Change Data Feed** preview from the workspace **Previews** page.
- **A Lakebase Autoscaling project with tables.** Run `databricks postgres list-projects --profile <PROFILE>` and confirm your Autoscaling project appears. A `not enabled` error means Lakebase is unavailable to this identity. This template does not cover project creation — see [Create a Lakebase Project](/templates/lakebase-create-instance) if you need one. CDF also requires Postgres 17 Autoscaling, tables in the `databricks_postgres` database with `REPLICA IDENTITY FULL`, and **CAN MANAGE** on the project.
- **Unity Catalog access.** Run `databricks catalogs list --profile <PROFILE>` to confirm the destination catalog exists, then `databricks schemas get <CATALOG>.<SCHEMA> --profile <PROFILE>` (or `databricks schemas list <CATALOG>`) to confirm the schema. You need `USE CATALOG`, `USE SCHEMA`, and `CREATE TABLE` on the destination, and the destination catalog must not use default storage.
